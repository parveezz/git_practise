# Git Practise

A hands-on project for learning and practising Git commands used in software development.

## Objectives

- Understand Git fundamentals.
- Learn how to create and manage branches.
- Practise staging and committing changes.
- Learn how to push and pull code using GitHub.
- Understand stashing, merging, and resolving conflicts.

## Git Commands Practised

| Command | Purpose |
|---|---|
| `git init` | Initialize a repository |
| `git status` | Check working tree status |
| `git add .` | Stage changes |
| `git commit -m "message"` | Create a commit |
| `git branch` | List local branches |
| `git branch branch-name` | Create a branch |
| `git switch branch-name` | Switch branches |
| `git log --oneline` | View compact commit history |
| `git remote -v` | View remote repositories |
| `git push -u origin branch-name` | Push and set upstream |
| `git pull origin branch-name` | Fetch and integrate remote changes |
| `git stash` | Temporarily store uncommitted changes |
| `git stash pop` | Restore stashed changes |
| `git merge branch-name` | Merge another branch into the current branch |

## Branches

- `main` — Main development branch.
- `dev-parveez` — Parveez's development branch.
- `dev-fareed` — Fareed's feature branch.

## Typical Git Workflow

1. Create or switch to a feature branch.
2. Make code changes.
3. Stage the changes using `git add`.
4. Commit the changes using `git commit`.
5. Push the branch to GitHub.
6. Create a pull request for review.
7. Merge the approved changes into `main`.
